# 💬 AI Sentiment Analysis

An AI-powered sentiment analysis web application that analyzes text and customer reviews using Natural Language Processing (NLP) and a pretrained BERT-based Transformer model.

## 🚀 Features

- 📝 Analyze individual text
- 📂 Upload CSV files
- 🤖 Analyze multiple reviews
- 😊 Positive sentiment detection
- 😐 Neutral sentiment detection
- 😞 Negative sentiment detection
- 📊 Sentiment distribution chart
- 🥧 Sentiment overview
- 🎯 Confidence score
- 📥 Download analyzed results as CSV
- 📈 Dashboard metrics

## 🛠️ Technologies Used

- Python
- Streamlit
- Transformers
- BERT
- spaCy
- Pandas
- Matplotlib
- PyTorch
